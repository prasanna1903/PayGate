# PayGate AI Prompt History

## AI tools used

### ChatGPT

AI assistance supported project planning, understanding payroll validation,
debugging, test planning and review, and interview preparation.

### GitHub Copilot

AI assistance supported backend implementation, the twelve validation rules,
database integration, approval and export workflows, evaluation scorecard,
React dashboard, API integration, and project documentation.

## Important representative prompts

The following are concise summaries of representative prompt themes:

- Design a payroll validation system that detects errors before export.
- Implement deterministic synthetic payroll data generation.
- Develop configurable payroll validation rules and an exception engine.
- Implement approval, waiver and export-gate workflows.
- Build a scorecard using true positives, false positives, false negatives,
  precision, recall and F1.
- Develop a React dashboard connected to FastAPI.
- Write setup instructions and project documentation.
- Test the complete application and fix identified issues.
